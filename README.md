
# Smart Shopping Billing System

A Python-based shopping billing application.

## About
This project allows customers to select products,
enter quantities and generate a shopping invoice.

## Features
- Multiple product selection
- Quantity management
- Automatic bill calculation
- 10% discount on purchases above ₹2,000
- Input validation
- Formatted invoice

## Technology
- Python 3

## Concepts Used
- Variables and operators
- Conditional statements
- Loops
- Dictionaries
- Functions
- Exception handling

## How to Run

1. Install Python 3.
2. Open the project folder in Terminal.
3. Run:

python3 main.py
